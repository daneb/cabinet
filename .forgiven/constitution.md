# Project Constitution
Building a Chess Analysis tool to walk through an Opening.

## Language
1. React
2. HTML
3. CSS

## Style
1. It should be aim to keep a classic look and style
2. The design should be minimal in order to keep focus on the analysis

## Architecture
1. We should build features in veritical slices 
2. The Chess Engine needs to be highly performant and not slow down the user interaction
3. User movement of pieces should be fluid

## Hard rule
1. We should not lose any games stored.
2. We should be able to save state and roll forward or back.
3. Performance is critical
